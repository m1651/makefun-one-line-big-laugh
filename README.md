# One Line, Big Laugh

A make.fun bounty entry: a Python program that writes a single funny line
of at most 200 characters to `entry.txt`.

## The entry

> My bank sent me a fraud alert about my own spending, which is fair — I barely recognize that person either.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-line-big-laugh-out python3 main.py
cat /tmp/one-line-big-laugh-out/entry.txt
```
